# 架构说明

一句话：**把"改得对不对"变成一个可以由机器判定的问题**。
生成环节可以换（规则模板 / 模型 API），但过不过得去，只看行为是否与存量等价。

## 2. 五个关键设计

### 2.1 闸门是"否决权"，不是"打分"

`equiv.gate()` 里五项检查任一不过，结论就是 `fail`，没有任何加权。
工具本身出问题（Harness 崩溃、巡检器退出码非 0）也判 `fail`——
**宁可误杀，不可放过**。因为静默破坏的代价远高于一次返工。

### 2.2 失败必须能自动闭环

`workflow.yaml` 里 `/equiv-check` 配了 `on_fail`：

```yaml
on_fail:
  remediate: auto_repair
  goto: migrate-module
  max: 2
```

`auto_repair` 先看闸门报告再决定策略：

- 命中 `TX-001` / `EX-007`（结构缺陷）→ 应用确定性补丁，回生成节点复用补丁，不重生成
- 有语义差分 → 把失败用例写成 `patch/regeneration-brief.json`，回灌给模型重生成
- 都没有 → 如实返回"未识别到可自动修复的问题"，链路终止

### 2.3 用例不够就是闸门不够

人工挑的 5 条用例覆盖的是"想得到的场景"。`testgen.py` 做三件事：

1. **等价类 + 边界值**：把金额切成 10 个等价类，含 `(0, 0.005)` 这种零邻域
2. **两两组合**：3 个维度 90 种全组合，用贪心集合覆盖压到 41 例，两两覆盖率保持 100%
3. **最小化**：对失败输入做二分收缩，给出最小复现

实测：某个"金额先舍入再判零"的实现，编译过、契约测试过、人工 5 例 0 差异，
算法用例发现 **24 处差异**（0.001 / 0.004 × 4 种订单号 × 输出/异常/SQL）。

### 2.4 上下文工程：接口面从代码里抽，不靠人写提示词

`codesurface.py` 扫 `common/src` 的公共签名，塞进提示词的"已存在的接口面"一节。
加这一节之前，模型会写 `BigDecimal amount = request.getAmount()`（存量返回 `double`），
第一次编译就挂；加上之后一次通过。

### 2.5 效率必须能配对，且两臂同源

`efficiency.py` 的 A/B：

- A 臂 = 基线（同一模型、同样两次机会，只回灌 javac 报错）
- B 臂 = 平台（接口面 + 硬约束 + 五项闸门 + 失败回边）

配对的硬约束：**两臂必须同一生成器**。A 是模型、B 是规则模板时，
`ab()` 直接报 `pairing_error`，所有差值置空、界面显示"不可配对"，
而不是算出一个好看但无意义的百分比。

## 3. 一次运行的完整数据流

```
/scan-arch       源码 → code-graph.json / table-lineage.json / tx-boundary.yaml
/extract-rules   rules/*.json → 带来源与置信度的规则表
/plan-migration  映射表 → 6 条计划 / 风险清单（等人签核）
   ↓ 人工签核（不签核不生成代码）
/migrate-module  适配器 → ModernSettleService.java + generation.json（含 token / 自检结果）
   ↓ 并行三路
   ├─ /audit-deps    依赖白名单 + 定点数检查
   ├─ /api-surface   公共方法面比对
   └─ /equiv-check   编译 / 契约 / 特征 / 双跑差分 / AST 巡检
        ↓ 不通过
        auto_repair → 补丁 或 证据回灌 → 回到 /migrate-module → 复检
/gen-regression  差分用例 → 可编译的特征测试 + 覆盖率说明
/report-delta    汇总实测值 + 效率机制 + 关键路径 → delta-summary.json
```

每一步的中间产物都落在 `hub/artifacts/`，可单独回放；重置不删除，只归档到 `hub/runs/`。

## 4. 为什么零第三方依赖

Node 用原生 `http`，Python 只用标准库，AST 用 JDK 自带 Compiler Tree API。
代价是要自己写 YAML 解析（`miniyaml.py`，140 行）和 HTTP 路由，
收益是**解压即跑**：不需要 `npm install`、`pip install`、Maven 仓库可达。

对一个要给别人演示、还要在 CI 里跑的工程，这个取舍是值得的。
